# Security reports

This experimental fork is maintained by [maschwenk](https://github.com/maschwenk), independently of Microsoft. For a vulnerability introduced by this fork, use [GitHub's private vulnerability reporting](https://github.com/maschwenk/typescript-go-tsrs/security/advisories/new) when available. Do not publish credentials or exploit details in an issue. If private reporting is unavailable, contact the maintainer through their GitHub profile to arrange a private channel.

Include the affected fork commit, a minimal reproducer and the security impact. Compiler diagnostic differences, ordinary crashes and performance regressions belong in this repository's issue tracker.

For an issue that also affects the upstream Microsoft compiler, follow [Microsoft's security policy](docs/upstream-security.md) and reporting process. Microsoft does not maintain or provide support for this fork.
